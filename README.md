# Sales Summary Using SQLite Python

## Objective

The objective of this project is to perform basic sales data analysis using SQLite and Python. The project demonstrates how to create a database, store sales records, execute SQL queries, analyze sales performance, and visualize business insights using Python libraries such as Pandas and Matplotlib.

## Dataset

The project uses a SQLite database named `sales_data.db` containing a single table called `sales`.

### Sales Table Structure

| Column Name | Data Type | Description |
|------------|----------|-------------|
| product | TEXT | Product Name |
| quantity | INTEGER | Number of Units Sold |
| price | REAL | Price Per Unit |

### Sample Records

| Product | Quantity | Price |
|----------|----------|--------|
| Laptop | 5 | 50000 |
| Mobile | 10 | 20000 |
| Headphones | 15 | 1500 |
| Laptop | 3 | 50000 |
| Mobile | 5 | 20000 |

## Tools Used

* Python
* SQLite (sqlite3)
* Pandas
* Matplotlib
* Google Colab

## Project Features

* Creates and connects to a SQLite database.
* Stores sales data in a relational table.
* Executes SQL queries for business analysis.
* Calculates product-wise sales quantity and revenue.
* Displays query results using Pandas DataFrames.
* Generates revenue visualization using Matplotlib.
* Saves charts for reporting and presentation.

## Key Insights

* Laptops generated the highest overall revenue despite lower sales volume.
* Mobile phones contributed significantly to total revenue and quantity sold.
* Headphones recorded the highest sales volume but generated lower revenue due to lower pricing.
* SQL aggregate functions such as SUM() and GROUP BY provide quick business insights from transactional data.

## Outcome

This project successfully demonstrates how SQL and Python can be integrated for data analysis. By combining SQLite, Pandas, and Matplotlib, sales data was stored, queried, analyzed, and visualized effectively. The project serves as a beginner-friendly introduction to database-driven analytics and reporting.
